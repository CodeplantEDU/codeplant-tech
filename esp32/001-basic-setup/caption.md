CODEPLANT TECH | ESP32 01 · 기본 세팅부터 첫 실행까지

Thonny는 PC에서 코드를 쓰는 도구, MicroPython은 ESP32에서 코드를 실행하는 펌웨어입니다. 둘의 역할부터 구분하고 데이터용 USB 케이블로 연결해 봅니다.

실행 대상을 MicroPython (ESP32)와 실제 COM 포트로 선택하세요. print(1 + 1)의 응답을 확인한 뒤, 숫자 1~5를 출력하는 코드를 실행하고 sleep(1)을 sleep(2)로 바꾸어 출력 간격을 비교해 보세요.

대상: ESP32 DevKit v1 · ESP-WROOM-32 계열 30핀 / Micro-USB. S3·C3·S2는 펌웨어가 다릅니다. 펌웨어 설치의 플래시 지우기는 기존 파일을 삭제하므로 먼저 백업하세요. 이번 편은 USB만 연결합니다.

전체 코드와 연결 방법은 아래 GitHub 주소에서 확인하세요.
