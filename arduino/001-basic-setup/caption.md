아두이노를 처음 쓴다면 Arduino IDE부터 알아보세요.
IDE는 보드에 무엇을 할지 적고, 그 코드를 보드에 보내는 프로그램입니다.

댓글에 'git'을 남기면 전체 코드와 연결 방법이 있는 GitHub 링크를 DM으로 보내드려요.

UNO 연결 → 보드·포트 선택 → 예제 코드 보내기 → 불빛과 문장 확인.
설치부터 업로드까지 화면별 안내와 전체 코드는 GitHub에 정리했습니다.

설치 파일: https://www.arduino.cc/en/software
