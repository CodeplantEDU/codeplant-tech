디지털로 온도를 읽는 DS18B20 · 아두이노 UNO 버전

전체 코드와 연결 방법은 아래 GitHub 주소에서 확인하세요.

DS18B20은 온도를 숫자로 바꾸어 D2 데이터선으로 전달합니다. 이번에는 TO-92 3핀 센서 한 개를 사용합니다. 1-Wire는 데이터선이 하나라는 뜻이며 전원과 접지도 연결해야 합니다.

준비물: UNO R3, DS18B20 TO-92, 4.7kΩ 저항, 브레드보드, 점퍼선, USB 데이터 케이블. USB를 빼고 글씨 있는 평평한 앞면을 앞으로, 다리를 아래로 둡니다. 왼쪽 1번 GND→UNO 위쪽 GND, 가운데 2번 DQ↔D2, 오른쪽 3번 VDD→5V. 4.7kΩ 저항은 DQ와 5V 사이입니다. 방수 케이블형·모듈형에는 이 좌우 순서를 그대로 적용하지 않습니다.

Arduino IDE에서 DallasTemperature와 OneWire를 설치한 뒤 전체 코드를 업로드하세요. 시리얼 모니터는 9600 baud. temp_C=섭씨온도가 반복해서 나옵니다. 센서 몸통을 손으로 가볍게 감싸고 놓으며 변화를 비교하세요. ERROR: DS18B20이면 USB를 빼고 배선·저항·부품을 확인합니다.

이 코드는 변환 완료를 기다리는 12비트 설정입니다. 1초 대기 외에 변환 시간이 더해집니다. 소수점 두 자리가 센서 정확도를 뜻하지는 않습니다. 불·뜨거운 물·침수는 사용하지 마세요.
