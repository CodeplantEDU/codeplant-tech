손으로 값을 바꾸는 가변저항 · 아두이노 UNO 버전

댓글에 'git'을 남기면 전체 코드와 연결 방법이 있는 GitHub 링크를 DM으로 보내드려요.

3핀 10kΩ 선형 가변저항을 돌려 A0의 입력값을 읽습니다. 양끝은 5V·GND, 가운데 접점은 A0에 연결하세요. 이 편의 그림은 UNO의 위쪽 GND를 사용합니다.

준비물: UNO R3, Adafruit 제품번호 562와 같은 3핀 10kΩ 선형 가변저항, 브레드보드, 점퍼선 3개, USB 데이터 케이블. USB를 빼고 세 다리를 서로 다른 연결 줄에 꽂습니다. 가운데 다리와 양끝을 제품 핀표로 확인하세요.

전체 코드를 업로드하고 시리얼 모니터를 9600 baud로 엽니다. 100ms마다 raw=숫자가 나옵니다. 숫자는 기본 설정의 UNO ADC 입력값(0~1023)이며 저항(Ω)이나 회전 각도가 아닙니다. 손잡이를 천천히 돌리고, 멈췄을 때 값이 어떻게 바뀌는지 비교하세요. 양끝 전원을 바꾸면 증가하는 방향이 반대가 됩니다.
