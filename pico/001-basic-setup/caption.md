01 · Raspberry Pi Pico에 MicroPython 설치하고 첫 코드 실행하기

RP2040 Raspberry Pi Pico와 Micro-USB 데이터 케이블을 준비하세요. BOOTSEL을 누른 채 USB로 연결하고, RPI-RP2 드라이브에 Pico 전용 UF2를 복사합니다. Thonny에서 Pico 인터프리터를 고른 뒤 F5를 눌러 보세요. 내장 LED가 세 번 깜박이고 Shell에 Pico ready와 Done이 차례로 표시됩니다.

전체 코드와 연결 방법은 아래 GitHub 주소에서 확인하세요.
https://github.com/CodeplantEDU/codeplant-tech/tree/main/pico/001-basic-setup

Pico 사진: MicroPython 공식 Pico 배포 페이지. Thonny 화면: Thonny 공식 사이트. 출처를 표시하며 별도의 사진·화면 재배포 라이선스는 확인되지 않았습니다.
