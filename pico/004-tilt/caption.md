CODEPLANT TECH · Raspberry Pi Pico 04 | 2핀 볼 스위치로 기울기 감지하기

스위치를 기울이면 안의 금속 공이 움직여 접점이 열리거나 닫힙니다. Pico의 GP15와 GND에 연결하고, 같은 상태가 50 ms 동안 이어지면 Thonny Shell에 출력해 보세요. USB 케이블을 뺀 뒤 배선하고 스위치에 전원 핀을 연결하지 마세요.

전체 코드와 연결 방법은 아래 GitHub 주소에서 확인하세요.
